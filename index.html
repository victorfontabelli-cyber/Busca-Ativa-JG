📌 Busca Ativa – Escola Estadual João Guidotti

Registro de faltas + mensagem pronta + atalho direto para WhatsApp por turma.

⚙️ Configuração rápida

1) Cadastre o link do grupo WhatsApp em cada turma (uma vez só).
2) Faça upload de um TXT/CSV com os dados (ou tire foto para registrar).
3) O app detecta automaticamente 2 ou mais F consecutivos e gera a mensagem padrão.
Formato recomendado do arquivo (TXT ou CSV):
Cada linha = um aluno.
Exemplo:
MARIA EDUARDA; C C F F C
JOÃO PEDRO; C F F F C

O app entende automaticamente F e C.
Feito para uso escolar. Dados ficam somente no seu navegador (LocalStorage).
